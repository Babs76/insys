## How to accept a contract change now
Run the tests with `INSYS_UPDATE_OPENAPI=1` (it writes the build-time document to `docs/api`), commit, and build the host again so it embeds the new copy. `TheServedDocument_IsTheCommittedCopy` fails until the host is rebuilt, by design.

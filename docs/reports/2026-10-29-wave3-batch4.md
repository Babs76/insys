## Not in this batch
- **The static-data document's reference fields.** The catalogue types them as "Ref X" (308 fields, such as Ref Product, Ref Country, Ref Role). "X" is an entity name, not a table: Ref Product is a Product Factory record, Ref Country is `refdata.ref_countries`, Ref TemplateVersion is a template and its version, Ref Scheme is a Health sponsor scheme. Mapping them needs a reviewed name-to-table-and-column list, which is hand work, so per Ade's rule it is left for later.
- **Title and gender codes** (`PartyIndividualData.titleCode`, `genderCode`) name `party.ref_personal_attribute_code_lists` with no `x-code-list-filter`, so a client would offer every list's values. Their `list_code` values are not specified (only `MARITAL_STATUS` has a sample). Not changed here; to decide with the front end.
- **Count:** the earlier estimate of about 258 undeclared fields counted …Code fields only; the test's rule includes …Type and lists of strings, hence 392.
